# Security policy

This alpha app is an unauthenticated scientific prototype. Do not submit confidential, restricted or personally identifiable research data to a public deployment. Files are parsed server-side and are not deliberately persisted by the application, but infrastructure and hosting may retain logs or runtime artifacts.

Report a security issue privately to the repository owner using GitHub's private vulnerability reporting (if enabled) instead of publishing exploit details in an issue. No security audit, hardening certification or service-level guarantee is claimed.
